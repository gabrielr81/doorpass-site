# doorpass.vip v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn doorpass.vip into a dark, dramatic, sign-up-first SaaS site with real pricing, a centered hero with a sixth "Game Day" venue, and human-like crowd motion.

**Architecture:** Same static site (`public/` served by nginx). One stylesheet (`public/css/styles.css`) gets a dark token set and a radius scale; `public/index.html` is restructured into 9 sections; `public/js/main.js` gains plan-aware form behavior; hero venue SVGs are regenerated by `tools/hero/*.py` into new `-v2` bundles. Node `node:test` guards every rule.

**Tech Stack:** HTML, CSS custom properties, vanilla JS, Node 22 `node:test`, Python + Playwright (hero tools only), nginx, Docker on the Hostinger VPS.

**Spec:** DoorPass Project doc `claude/doorpass-site-v2-design.md` (approved Nov 26 2026). Copy it to `docs/superpowers/specs/2026-11-26-doorpass-site-v2-design.md` in Task 1.

## Global Constraints
- Brand: orange `#F2553F`, navy `#0A1128`, white `#FFFFFF`; Poppins 400/700 self-hosted; logo files never redrawn or recolored.
- Orange is never a text color on white; on dark it is allowed only for highlights (numbers, "Pass", links).
- Radius scale: `--r-xs: 4px; --r-sm: 8px; --r-md: 12px; --r-lg: 16px; --r-pill: 999px`. Buttons/inputs `--r-sm`, cards `--r-md`. Hero scene, QR, scanner art: `0`.
- Prices (exact): Hosted **$99/month**, 500 capacity and under, up to 10 events a month, "connect your own Twenty CRM free". Dedicated **$499/month + $1,500 setup**, over 500, unlimited, Twenty CRM setup **$199 one-time**.
- Payment wording: "Connect your own Stripe. Money goes straight to you." and "No per-ticket fees." Never claim DoorPass processes, holds or takes a cut of payments. Never mention paid Twenty setup help for Hosted.
- Never: "24 hours", "free pilot", "MOCK PRICES", "coming soon" next to payments, "under 1,000".
- Keep `DATA_SENTENCE` (in `test/content.test.js`) word for word on the home page and privacy page.
- No framework, no build step, no third-party CDN, no inline `style=""` (CSP). Changed `/assets` files get a new `-vN` name.
- PageSpeed mobile ≥ 90 on all four scores after any task touching CSS or hero; no horizontal scroll at 320 px; hero centered at 2560 px.
- Workflow: one task = one issue in `gabrielr81/doorpass-site` = one branch `v2/<n>-<slug>` = one PR with `Closes #N` and test output. Gabriel granted merge and deploy. Deploy = merge to `main`, restart Docker project `doorpass-site` via the Hostinger connector, verify in the built-in browser.
