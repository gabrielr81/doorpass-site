How to create promo and comp codes

Codes let you reward a promoter, give a sponsor free entry or run a discount, without touching each order by hand.

Request access See the live demo

The steps

  • Open Promo codes on the event. In the admin, open the event and choose Promo codes.
  • Pick the type of code. Choose percent off, dollars off the order, or free (comp).
  • Limit it if you want. Optionally limit a code to one ticket type, a number of uses or a last day.
  • Guests enter it on the event page. Guests tap Have a promo code? on the event page, or use the field in the website embed. The discount shows at checkout, on the order page and on the receipt.
  • Turn a code off without deleting it. Turn off stops a code from working. Past orders keep their discount.
  • Read the report. The event report lists the uses and the discount given for each code. Refunds give back what the guest actually paid.

To credit a promoter's sales, add ?ref=name to the event link. Codes and referral links work together.

Questions venues ask

What kinds of promo codes can I create?

Percent off, dollars off the order, or free (comp) codes. You can limit a code to one ticket type, a number of uses or a last day.

Can I stop a code without deleting it?

Yes. Turn off stops the code from working while past orders keep their discount.

Where do guests enter a promo code?

On the event page under Have a promo code?, or in the field in the website embed.

Can we sell paid tickets with DoorPass?

You can run free events, door lists and test-mode checkout today. Card payments with Stripe are coming soon.
