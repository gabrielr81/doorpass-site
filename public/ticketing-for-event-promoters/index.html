DoorPass / Promoter ticketing

Ticketing for event promoters

Promoters need to know who sold what, and to reward them for it. DoorPass credits every ticket to the link it came through and shows it in the event report.

Request access See the live demo

What a promoter gets

  • A link for every promoter. Add ?ref=name to the event link. Tickets bought through it are credited to that name.
  • Reports by promoter link. The event report shows tickets, check-ins, and sales by ticket type and by promoter link.
  • Promo and comp codes. Create percent-off, dollars-off or free codes, limited to a ticket type, a number of uses or a last day. Turn a code off any time.
  • Import a guest list. Paste first and last names with emails, up to 300, and each guest gets a QR code.
  • Sell on your own site. Add two lines of code and your events appear on your website, with checkout in a pop-up.
  • Email everyone with a ticket. Message all ticket holders, only those not in yet, or only those already in.

DoorPass is set up per venue or organizer: each customer gets their own copy. Tell us how you run events and we will set it up.

Questions venues ask

How do I credit sales to a promoter?

Add ?ref= and the promoter's name to the event link. Tickets bought through it are credited to that name in the event report.

Can I give a promoter a discount code?

Yes. Create a percent-off, dollars-off or free code, and limit it to a ticket type, a number of uses or a last day.

Do guests need an app?

No. Guests get a QR ticket by email and staff scan in a browser.

Can we sell paid tickets with DoorPass?

DoorPass runs free and paid events and door lists. Paid tickets go through your own Stripe account, so the money goes straight to you, with no per-ticket fees from DoorPass.
